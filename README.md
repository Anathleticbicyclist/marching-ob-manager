# 🚴 迈向Ob管理器 (Marching OB Manager)

**本地运动数据中心 · 让每一份 FIT / GPX 都能被看见**

一个**纯本地、无后端、零上传**的运动数据查看与整理工具：扫描本地运动文件，生成个人数据中心、生涯统计、日历热力图与年度轨迹海报，支持全内存搜索、查重、去重与 JSON 索引备份。

> 所有解析、索引、统计都在浏览器本机完成；不联网、不上传、不依赖账号。

## ✨ 功能

- **本地扫描**：支持文件夹递归扫描、多选文件、整目录拖拽导入；识别 `.fit` / `.gpx` / `.tcx`
- **数据解析**：自研 FIT 二进制解析器（文件头 / Definition / Data / 压缩时间戳）+ GPX/TGX 轻量 XML 解析
- **数据中心**：活动列表、距离/时长/爬升/均速/心率/功率等摘要，点开查看详情与轨迹小地图
- **生涯统计**：总距离、总时长、总爬升、活跃天数、最长连续、单日最远、最快均速
- **年度统计**：年份切换、月度分布、年度目标进度（距离 / 次数）
- **日历热力图**：GitHub 风格 53×7 年视图，按日距离强度分 4 档
- **个人最佳**：5K / 10K / 半马 / 全马（含合理配速过滤）+ 最长单次骑行、最大爬升、最快均速
- **年度海报**：把当年所有轨迹绘制为暗色轨迹海报，导出 SVG
- **全内存搜索**：名称 / 文件名 / 运动类型 / 日期 / 设备，多关键词空格分词
- **查重与去重**：精确文件哈希（SHA-256）+ 活动指纹（运动类型+开始时间+时长+距离）双重比对，支持"保留最新/最早"
- **JSON 备份**：导出/导入完整索引，换浏览器也能迁移
- **隐私优先**：数据仅存 IndexedDB；不联网、不上传、无统计埋点

## 🚀 快速开始

### 方式一：直接打开（最简单）

下载/克隆本仓库后，用 Chrome / Edge 打开 `index.html` 即可。

> 建议用「选择文件夹」扫描本地 FIT 目录（如 Garmin/迈金/iGPSPORT 导出的运动文件）。

### 方式二：本地静态服务（推荐，兼容性最好）

```bash
# 任选其一
python -m http.server 8080
# 或
npx serve .
```

浏览器访问 `http://localhost:8080`。

> `file://` 下 Chrome/Edge 的文件夹扫描与 IndexedDB 一般可用；若遇到限制，请用上面的静态服务方式。

### 方式三：GitHub Pages

仓库启用 Pages（main 分支根目录）后，可直接在线使用。数据仍只存在你的浏览器本地。

## 📂 支持的格式

| 格式 | 说明 | 读取内容 |
|------|------|----------|
| `.fit` | Garmin FIT（二进制） | 时间、距离、时长、爬升/下降、均速/极速、心率、功率、踏频、卡路里、轨迹点、运动类型、活动名称、设备 |
| `.gpx` | GPS Exchange（XML） | 轨迹点、海拔、时间、名称/类型 → 距离/时长/爬升/均速/心率（若含） |
| `.tcx` | Training Center XML | 轨迹点、海拔、时间、心率、距离、卡路里、最大速度 |

运动类型自动归类为：骑行 / 跑步 / 徒步 / 步行 / 游泳 / 滑雪 / 划船 / 其他。

## 🔍 查重与去重

两条独立判据，命中任一即归为重复组：

1. **文件哈希**：SHA-256（浏览器不支持时回退 FNV-1a 64-bit），完全相同的文件才哈希相同；
2. **活动指纹**：`运动类型 | 开始时间(秒) | 时长(5 秒取整) | 距离(10 米取整)`，用于识别"同一活动不同文件/不同来源"。

查重页支持一键「保留最新」或「保留最早」，其余仅从索引移除——**不会删除磁盘上的原始文件**。

## 📐 统计口径

- **距离**：FIT session `total_distance`（0.01 m 精度）；GPX/TCX 用 Haversine 逐点累计；
- **时长**：优先 moving time（FIT `total_timer_time`），否则 elapsed/时间戳差；
- **爬升/下降**：FIT session 累计值；无 session 时按海拔差分（>0.2 m 计一次）累计，避免抖动虚高；
- **均速**：FIT session 均值；否则距离/时长；
- **个人最佳**：距离落在 ±5%~10% 档位、配速 3:00~8:00/km 内才计入，过滤 GPS 漂移；
- **热力图**：按日汇总距离，相对当年最大值分 4 档；
- **年度海报**：轨迹按经纬度归一化绘制，不依赖任何地图底图/Token。

```
marching-ob-manager/
├── index.html              # 单页应用入口（深色移动端 UI）

├── LICENSE
```

## 🧪 开发与测试

需要 Node.js（仅测试用，运行时不依赖任何第三方库）：

```bash
# 1) 生成样本文件（需要 Python 3）
python tools/gen_samples.py

# 2) 跑解析器 + 统计引擎测试
node tests/run_tests.js
```

当前测试覆盖：FIT/GPX/TCX 解析字段、距离/时长/爬升/心率、生涯统计、热力图网格、月度分布、PB、去重分组、海报 SVG 生成（30 项断言）。
